RepFuel Protein Tracker

Open html/index.html in a browser. No install or build step is needed.

Folder guide:
- html/index.html: app page
- css/style.css: maroon glass theme, bento layout, responsive styling
- javascript/app.js: tracker behavior, profile, workout plans, food logging, history
- cpp/loops.cpp: standalone C++ sample from the existing project; the website itself does not need C++.

The tracker saves your profile and logs in the browser on this device.
